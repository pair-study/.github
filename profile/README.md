## 📚 스터디

### 목표
- 미션을 함께 수행하며 구현력과 리뷰 역량을 함께 키운다.
- 각자의 풀이를 비교하며 더 나은 설계와 표현 방식을 고민한다.
- 세션 기록을 남기며 학습 내용을 정리하고 누적한다.

### 미션 목록

| # | 미션 | repository README | 키워드 |
|---|---|---|---|
| 1 | 숫자 야구 게임 - MVC 패턴 적용 | [세션 기록](https://github.com/pair-study/javascript-baseball-precourse/blob/main/README.md) | `MVC`, `ES6 클래스` |
| 2 | React 공식 문서 기반 실습 - 음식점 앱 구현 | [세션 기록](https://github.com/pair-study/self-paced-react/blob/main/README.md) | `useState`, `useEffect`, `useCallback` |

### 진행 방식
1. 각자 브랜치에서 미션 수행
2. PR 생성 후 상호 코드 리뷰
3. 스터디 세션에서 리뷰 답변 및 논의
4. 각 미션 repository README에 세션 내용 기록

### 규칙

#### 📝 개인 README
- 개인 목표
- 가장 많이 고민한 문제와 해결 과정에서 배운 점 (최소 3가지)
- _(@ehlung only)_ 과거 코드와 비교 — 달라진 점, 그로부터 배운 점

#### 🔀 PR
- 개인 목표 달성 여부
- 페어와 논의하고 싶은 부분을 체크리스트로 작성

#### 💬 코드 리뷰

리뷰 코멘트에는 아래 태그를 붙여 작성해요.

| 태그 | 용도 |
|---|---|
| `[질문]` | 나와 다르게 푼 부분, 이유가 궁금할 때 |
| `[제안]` | 이렇게 하면 어떨까? |
| `[배움]` | 몰랐던 문법/패턴, 나도 써봐야겠다 싶을 때 |
| `[논의]` | 둘 다 확신 없어서 같이 찾아봐야 할 때 |
